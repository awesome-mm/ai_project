Talk To Figma MCP Plugin를 적용해서 channel을 바꿔가며 적용한다

- 피그마에서도 활성화를 해주어야하고 cursor에서도 아래 mcp 코드를 사용해야한다
- bun이라는것이 없을 때는 설치하고 적용해야한다
{
  "mcpServers": {
    "TalkToFigma": {
      "command": "bunx",
      "args": [
        "cursor-talk-to-figma-mcp@latest"
      ]
    }
  }
}

피그마에서 사용법 
1. ctrl + l  키를 눌러서 링크복사
2. 오른쪽마우스 -> copy/paste as -> copy link to selection 
( 두가지 다 복사하여 얻는 값은 동일함 )
